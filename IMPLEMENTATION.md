# SDD Implementation Notes

This React app consumes the Laravel `/api/v1` contract documented in the English SDD adaptation.
It keeps business enforcement on the backend and provides the required operational flow:

- Login.
- Catalog search and book creation.
- Member search and creation.
- One-book loan creation flow, overdue list, and most-borrowed report view.

Run with:

```bash
npm install
npm run dev
```
